# House Price Category Prediction Web App

## Overview
This project is a machine learning web application built with Streamlit that predicts house price categories based on property features such as size and number of bedrooms.

The application integrates a Logistic Regression model trained for classification tasks and provides an interactive user interface for real-time predictions.

---

## Features
- Interactive Streamlit web application
- Predicts house price categories instantly
- User-friendly input controls
- Logistic Regression machine learning model
- Lightweight and fast deployment

---

## Technologies Used
- Python
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Joblib

---

## Project Structure

├── app.py

└── README.md

---

## How It Works
The user provides:
- Property size
- Number of bedrooms

The trained Logistic Regression model processes the inputs and predicts the corresponding house price category.
